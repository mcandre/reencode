# reencode: video normalizer

[![CI/CD](https://badgen.net/github/checks/mcandre/reencode?icon=github)](https://github.com/mcandre/reencode/actions) [![License](https://badgen.net/static/license/BSD/ab2b29?icon=freebsd)](LICENSE.md)

# SUMMARY

reencode unifies videos to the exceptionally portable (x264, AAC) MP4 format.

# EXAMPLE

```console
$ reencode video.avi

$ ls
video.avi
video.mp4
```

# DOWNLOAD

```sh
git clone https://github.com/mcandre/reencode.git ~/src/github.com/mcandre/reencode
```

## Prerequisites

* [bash](https://www.gnu.org/software/bash/) 4+
* [ffmpeg](https://www.ffmpeg.org/)
* [git](https://git-scm.com/)

## Postinstall

Register `"$HOME/src/github.com/mcandre/reencode/bin` to `PATH` environment variable.

For details on building from source, see [DEVELOPMENT](DEVELOPMENT.md).
